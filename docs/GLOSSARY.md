# Glossary

## KANSLI

The workspace and technical control plane across multiple independent product repositories.

## Product repository

A standalone Git repository for one product (ALVA/TORA/RITA/IRMA/BRITT), with its own history, releases, and deployment lifecycle.

## Control plane

Shared documentation, conventions, and platform foundations coordinated by KANSLI without absorbing product business logic.

## Shared foundation

A small set of robust shared components (identity, UI primitives, contracts, logging) used optionally by products.

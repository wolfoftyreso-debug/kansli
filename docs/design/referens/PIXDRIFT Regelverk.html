PIXDRIFT
Rulebook · the system environment · map

Anyone must understand.

The rulebook for every PIXDRIFT surface — screens, documentation, education, print. The premise is absolute: a person who reads no Swedish and no English still understands who does what, with what, and how it went. Words are captions, never carriers. These rules bind every system that exists and every system that comes.

01 · Five laws
1 · One figure, one meaning
Every figure means exactly one thing, everywhere. A tire is always the tire. A check is always done. Nothing is reused decoratively.
2 · State is shape plus color
Done is a green check. Blocked is a red bar. Waiting is gray dots. Color never carries meaning alone — the colorblind reader gets the same message from the shape.
3 · Everything reads left to right
Input on the left, outcome on the right, always. Time flows the same way. No surface mixes reading directions.
4 · One accent per view
Blue marks the one thing that matters right now — the moving data, the next action, the found result. Two accents means neither is the point.
5 · Words are optional
Every caption must survive deletion. If removing the text breaks the meaning, the figure is wrong — redraw the figure, don't add words.
+ · Motion shows the job
Figures assemble and breathe; the accent element does its work — travels, drops, pulses. Motion is meaning, never garnish, and reduced-motion freezes to a complete final frame.
02 · The sentence
Every explanation is the same wordless sentence: someone → does something → result. Subject from the people library, action from the work library below, outcome from the state language. Captions optional.

04 · Attaching state
Any scene, object or row takes a state badge in its top-right corner — the same four everywhere. Faces are for feedback from people; geometric marks are for the state of work. Never mix the two on one element.
Work states
Green check = done · amber filled dots = in progress · gray dots = waiting · red bar-square = blocked. Dot in tables, mark in cards, badge on scenes.
Human feedback
The expression faces (nöjd / neutral / missnöjd) speak only for people — customer ratings, session feedback. A machine never smiles.
05 · Never
— Meaning carried by text or color alone
— A figure that changes meaning between rooms
— Two accents in one view
— Right-to-left or bottom-up flows
— Faces on machines or objects
— Scenes invented outside the libraries
— Decorative motion
— Unicode emoji in any surface

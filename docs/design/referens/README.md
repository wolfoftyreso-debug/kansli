# Design proofs (living HTML)

Open these in a browser. Inline styles only. When prose and pixels disagree,
the HTML wins for visual grammar. Start at `PIXDRIFT Galleri.html`.

| File | Locks |
| --- | --- |
| PIXDRIFT Galleri.html | Index of every living proof |
| PIXDRIFT Karta.html | Index of the design program |
| PIXDRIFT Design.html | Tokens, chrome, components |
| PIXDRIFT Hem.html | Opening view tile grammar |
| PIXDRIFT Grafer.html | 2.5D chart language |
| grafer.js | Chart runtime for the Grafer proof (not imported into rooms) |
| PIXDRIFT Illustrations.html | Figure grammar + catalog-room models |
| PIXDRIFT Regelverk.html | Comprehension laws |
| Objektkatalog.html | 357 figures · 37 categories |
| Fordonsbibliotek.html | 13 size classes, 2D |
| fordon-3d.html | 13 size classes, orbitable 3D |
| tiguan-3d.html | One class (Tiguan) as a smaller stage |
| support.js | Viewer runtime for the HTML proofs |
| three-d-stage.js | 3D stage helper (not wired into rooms) |

The Hem and Design proofs show a 14-name wish list (SAGA, NORA, MOVA, …).
That is not a licence to invent products. The running launcher ships only
`@pixdrift/systems` rooms: Kansli, Ekonomi, TORA, RITA, BRITT, IRMA, TYRA,
ALVA, CREDITAE.

LANGUAGE and BEA in the proofs are settings tiles, not apps. Locale is the
chrome picker. 3D and the object catalog stay in referens. TYRA may name a
vehicle by size class; it does not embed three.js.

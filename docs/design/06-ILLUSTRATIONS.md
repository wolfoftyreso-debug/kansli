# Illustration System
References: referens/PIXDRIFT Illustrations.html (grammar + system models),
referens/Objektkatalog.html (357 figures · 37 categories).

Grammar: semi-realistic volumes, natural material colors (steel/wood/copper/brass/
cardboard gradients), one light source upper-left, specular highlights only on gloss,
soft radial ground shadow. Entry: rise 0.7s; idle: float 5s ±3-4px. Accent #1F4B8F
marks only the working element. People are stylised and faceless — expression marks
carry feeling; a machine never smiles. Show the work target, not just the tool.

Catalog coverage: every service trade (cleaning, waste, property, grounds, logistics,
office, editorial, car rental, education, finance, analysis, restaurants, construction,
electrics & plumbing, beauty, care, retail, hotels, laundry, IT, security, bakery,
gym, veterinary, real estate, school, agriculture, geography, risk, banking, tools,
power tools, automation) plus people, animals, arrows and expressions.
New categories are added in the same grammar — name the trade and its objects.

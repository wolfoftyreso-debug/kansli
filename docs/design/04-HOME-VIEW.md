Reference: referens/PIXDRIFT Hem.html (open in browser; markup is the spec).

Audience: the company's system administrator. Rarely visited — applications are
normally installed directly on the user's computer; this view governs what runs.

- Topbar 36px white, hairline bottom: PIXDRIFT wordmark · tenant + environment
  (mono 11 uppercase) · Support · Settings · Sign out (12px underlined links).
- Header: mono meta line (date · time · System administrator) + H1 greeting. Nothing else.
- "Applications · 14 installed": glass launcher tiles (02 §Launcher) — animated
  system model, name, mono category; description as tooltip. NO status rows.
- "Application settings · System administration": same tile grammar —
  BEA, COMPANY, LANGUAGE, INTEGRATIONS, DATA, GENERAL, APPEARANCE, VERSION.
- Tile click opens the app. Hover lift; respect prefers-reduced-motion.

# ALVA — designkälla i navet

ALVA-SPEC-001 (`DESIGN.md`) och ALVA-SPEC-002 (`ALVA-DESIGNSCHEMA.md`).
HTML-bevis: `alva-designschema.html`. När prosa och pixel skiljer sig vinner
HTML-filen.

## Vad som gäller här

PIXDRIFT-paketet i `docs/design/00-README.md` … `08` äger **chromet**
(fasad, launcher, IdP). ALVA-schemat äger **grammatiken i rummet** `/alva`:
status är ord plus tecken, sektioner är etiketter, tryckyta minst 48 px,
inga påhittade slutsatser.

Diagnosmotorn, AWS, en andra databas, DIN/IBM Plex som plattformssnitt
och ALVA:s egen server **följer inte med**. ALVA i det här repot tar emot
fel, anteckning och mätvärde. Systemet ställer ingen diagnos.

| Schema | I navet |
| --- | --- |
| Primärknapp `--blå` | Ink-rektangel (plattformens knapp) |
| DIN → IBM Plex | Geist (plattformens snitt) |
| `○ □ ✓ ✕` | Samma tecken, svenska ord bredvid |
| Försegling, hashkedja, portal | Inte byggt här |

`PAKETET.md` beskriver ALVA-repot som helhet. Det är källhänvisning, inte
en inbjudan att kopiera infrastrukturen.

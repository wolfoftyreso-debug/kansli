# KANSLI — Platform / Workspace Control Plane

KANSLI is the **workspace and technical control plane** for a family of independent B2B products:

- **ALVA** — diagnostics and guided troubleshooting
- **TORA** — public procurement
- **RITA** — tax, deductions, and incentives
- **IRMA** — agreements, digitalization, signing, and lifecycle
- **BRITT** — leadership, reporting, and business management

Core principle: **workspace first, not a monorepo**. Each product remains a separate Git repository with its own history, releases, and deployment lifecycle.

Open `kansli.code-workspace` in Cursor/VS Code to work across the full repository cluster.
